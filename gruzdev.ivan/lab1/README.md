# Лабораторная работа 1

## Задание

Вариант 38. Создать «хлебные крошки» (breadcrumbs). Требования: список, элементы
— ссылки, последний элемент — span, цвет ссылок #0056ff, подчёркивание ссылки
при наведении, цвет span #333, стрелки между элементами через псевдоэлемент
after.

## Реализация

Разметка — список `<ul class="breadcrumbs">`, каждый пункт — `<li>`. Первые два
пункта содержат ссылку `<a>`, последний — `<span>` с текущим разделом. Стрелка
между пунктами добавляется через `::after` на `<li>:not(:last-child)`, поэтому
после последнего пункта стрелки нет. Цвета и hover-подчёркивание заданы в
styles.css без inline-стилей и `!important`.

## Запуск

Открыть index.html в браузере — файл самодостаточен и не требует сборки или
сервера.
