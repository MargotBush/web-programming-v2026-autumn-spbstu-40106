# Лабораторная работа 1

## Задание

Вариант 18. Создать карточку товара с изображением, названием и ценой. При
наведении курсора на карточку должно происходить изменение её внешнего вида:

- Фон: Цвет фона карточки изменяется на светло-голубой (#e0f7fa);
- Тень: К карточке добавляется размытая тень с небольшим смещением (смещение
  тени по горизонтали и вертикали –5px, радиус размытия тени
- 10px, цвет тени – черный, прозрачность – 20%);
- Масштабирование: Размер изображения увеличивается на 10% от исходного размера.
- Все изменения должны происходить одновременно.

## Реализация

Карточка товара сверстана с помощью тега <article> и содержит изображение,
название и цену. При наведении hover: фон карточки изменяется на светло-голубой,
появляется тень, а изображение увеличивается на 10% с помощью transform:
scale(1.1). Для плавности изменений используется transition.

## Запуск

Откройте `index.html` в браузере.
