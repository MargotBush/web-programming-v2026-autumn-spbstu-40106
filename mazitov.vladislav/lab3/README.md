# Лабораторная работа 3

## Задание

Вариант 18. Реализуйте функцию findLongestIncreasingSubsequence(arr), которая
находит длину наибольшей возрастающей подпоследовательности.

## Реализация

Экспортируется функция findLongestIncreasingSubsequence, которая принимает
массив чисел и возвращает длину его наибольшей строго возрастающей
подпоследовательности.Создаётся массив dp, где dp[i] — длина наибольшей строго
возрастающей подпоследовательности, которая заканчивается на элементе arr[i].
Для каждого элемента проверяются все предыдущие элементы. Если arr[j] < arr[i],
то текущая длина может быть увеличена: dp[i] = max(dp[i], dp[j] + 1). Изначально
каждый элемент образует подпоследовательность длины 1. После обработки массива
максимальное значение в dp является ответом.

Пустой массив — возвращается 0.
