# Лабораторная работа 2

## Задание

18 Вариант. Написать функцию, которая проверяет, является ли строка панграммой
(содержит ли строка все буквы алфавита)

## Реализация

Строка переводится в нижний регистр. Затем её символы помещаются в сет, чтобы
получить набор уникальных символов. После этого проверяется наличие каждой буквы
английского алфавита в полученном наборе.

## Запуск

импортируйте ф-ю в проект:

```ts
import {isPangram} from './solution.ts';
```
