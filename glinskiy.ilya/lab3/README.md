# Лабораторная работа 3

## Задание

Вариант 34. Реализуйте функцию findPairsWithSum(arr, sum), которая возвращает
все пары чисел, дающие в сумме sum.

## Реализация

Экспортируемая функция возвращает массив с парами числе, дающими в сумме `sum`.
Алгоритм проходит через все возможные пары чисел в массиве и, если пара дает
сумму равную `sum`, то она добавляется в массив.

## Запуск

Импортируйте именованный export из `solution.js` как ES module.
